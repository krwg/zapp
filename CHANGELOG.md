# Changelog

All notable changes to zapp are documented here.  
Detailed release notes with installer hashes live on [GitHub Releases](https://github.com/krwg/zapp/releases); the `RELEASE_0.2.x.md` files in the repo mirror those notes.

Format inspired by [Keep a Changelog](https://keepachangelog.com/). Versioning follows semver for the app channel.

## [0.2.7] — 2026-11-21

Path verdicts on Home, recent working modes, watchdog, first-run wizard, conflict shield, locale-aware faults, faster Start→UAC, DNS/snapshot speedups, landing page.

Full notes: [RELEASE_0.2.7.md](RELEASE_0.2.7.md) · [Release](https://github.com/krwg/zapp/releases/tag/0.2.7) · [Compare](https://github.com/krwg/zapp/compare/0.2.6...0.2.7)

## [0.2.6] — 2026-11-20

Trust hardening (ProgramData engine + ACL, helper path allowlist), clearer errors / bug reports, richer Smart check ranking, Markdown release notes. No Telegram proxy.

Full notes: [RELEASE_0.2.6.md](RELEASE_0.2.6.md) · [Release](https://github.com/krwg/zapp/releases/tag/0.2.6)

## [0.2.5] — 2026-11-18

Hardened engine lifecycle (Bypass / helper / Quit / Cancel), probe and UI race fixes.
